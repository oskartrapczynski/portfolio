# Oskar T.T Portfolio - Design Overview

## 🎨 Visual Design Concept

### Color Palette

- **Background**: Deep black (#0a0a0a) with subtle grid pattern
- **Primary Text**: White (#ffffff)
- **Secondary Text**: Gray (#9ca3af)
- **Accent Colors**:
  - Neon Cyan (#00ffff) - Primary accent
  - Neon Blue (#00ffff) - Secondary accent
- **Borders**: Dark gray (#1f1f1f) transitioning to cyan on hover

### Typography

- **Display Font**: Space Mono (monospace) - Used for headings and technical feel
- **Body Font**: Inter - Clean, modern sans-serif for readability
- **Code Style**: Monospace throughout for developer aesthetic

## ✨ Animation Features

### On Page Load

1. **Hero text fades in** with upward motion
2. **Social icons** appear one by one
3. **Geometric shapes** start rotating
4. **Scanline** begins moving down the screen

### On Scroll

1. **About section cards** fade in with stagger
2. **Project cards** slide up as they enter viewport
3. **Contact section** animates corner brackets
4. **Navigation bar** gains background blur

### On Hover

1. **Buttons** glow brighter with neon effect
2. **Project cards** lift up with shadow
3. **Skill cards** gain neon border
4. **Social icons** scale up and float
5. **Links** change color to cyan

### Continuous

1. **Grid background** subtle pulse
2. **Geometric shapes** slow rotation
3. **Scanline** moves top to bottom
4. **Text glow** breathing effect
5. **Scroll indicator** bouncing motion

## 🎯 Special Effects

### Neon Glow

- Text shadow with multiple layers
- Box shadow for containers
- Pulsing animation on headings

### Grid Background

- Transparent cyan grid lines
- 50px spacing
- 10% opacity for subtlety

### Scanline Effect

- Single line moving vertically
- Cyan gradient
- 8s loop animation

### Glitch Effect

- Quick position shifts on hover
- Adds cyberpunk feel
- Applied to main heading

## 📱 Responsive Design

### Desktop (1024px+)

- 3-column grid for skills
- 3-column grid for projects
- Full navigation bar

### Tablet (768px - 1023px)

- 2-column grids
- Adjusted spacing
- Visible navigation

### Mobile (< 768px)

- Single column layout
- Hamburger menu
- Stacked sections
- Touch-friendly buttons

## 🎨 Design Philosophy

This portfolio embraces a **cyberpunk/neon aesthetic** that:

- Reflects technical expertise through monospace fonts
- Uses neon accents sparingly for maximum impact
- Creates depth through layering and shadows
- Maintains professional feel while being creative
- Balances dark backgrounds with bright accents
- Provides smooth, purposeful animations

The design puts **programming first** while showcasing creative versatility through the multi-category project system and diverse skill showcase.
